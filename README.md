# 🔐 Password Generator

A modern and secure Password Generator built using React.js.  
This application helps users generate strong random passwords with customizable options such as uppercase letters, lowercase letters, numbers, and symbols.

---

## ✨ Features

- Generate highly secure random passwords
- Adjustable password length
- Uppercase letters support
- Lowercase letters support
- Numbers support
- Symbols support
- One-click password copy
- Beautiful modern glassmorphism UI
- Fully responsive design
- Fast and lightweight application

---

## 🛠️ Tech Stack

- React.js
- JavaScript
- CSS3
- Crypto API
